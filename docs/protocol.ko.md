# 프로토콜 명세

모든 통신은 메시지 ID와 슬롯으로 이루어진다. `→` 는 서버 응답이다.

## 접속

- `id[0]` 클라이언트: 로그인방 접속 알림 (슬롯0 = 1)
  - `→ id[1]` 서버: 기본 정보와 공지 (슬롯0~12 = 공지사항)
  - `→ id[6]` 서버: 기본 정보 2 (슬롯0 = 제작자, 슬롯1 = 버전)

## 로그인

- `id[2]` 클라이언트: 로그인 요청 (슬롯0 = 아이디, 슬롯1 = 비밀번호)
  - `→ id[3]` 서버: 결과 (슬롯0 = 1 아이디 없음 또는 비밀번호 불일치, 슬롯0 = 2 통과)

## 가입

- `id[4]` 클라이언트: 가입 요청 (슬롯0 = 아이디, 슬롯1 = 비밀번호)
  - `→ id[5]` 서버: 결과 (슬롯0 = 1 중복 아이디, 슬롯0 = 2 통과)

## 로비

- `id[7]` 클라이언트: 로비 입장 (슬롯0 = 1)
  - `→ id[8]` 서버: 갱신된 플레이어 리스트를 전체에 브로드캐스트 (슬롯0 = 플레이어 리스트)
- `id[9]` 클라이언트: 퇴장 (슬롯0 = 자신의 아이디)
  - `→ id[8]` 서버: 갱신된 플레이어 리스트를 전체에 브로드캐스트 (슬롯0 = 플레이어 리스트)
- `id[10]` 클라이언트 → 모든 클라이언트: 전체 채팅 (슬롯0 = `아이디 - 채팅 내용` 형식으로 완성된 한 줄). 서버 처리 없이 클라이언트끼리 브로드캐스트한다
